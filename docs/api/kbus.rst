KajennBus and communication
===========================

The `KBusMixin`, which carries the server over the `kbus` library
(https://github.com/kajenn-org/kajenn-kbus): it adds `kbus_call`, `kbus_post`,
`serve_kbus_call` and `serve_kbus_message` to the server.
